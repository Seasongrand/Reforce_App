# Revisão de UX, lote 3: perfil, preços e navegação do professor (Implementation Plan)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** resolver A2, A3, m2, M2, M3 e M4 do relatório de UX.

**Architecture:** só telas e uma ação nova (nome no primeiro acesso). O cálculo de “você recebe” usa `splitCommission`, a mesma conta do repasse.

**Tech Stack:** Next.js 16, React 19, Tailwind 4, Vitest, Playwright.

**Spec:** relatório “Revisão de UX da Reforce” (https://claude.ai/artifact/TD6M6nKBTNVFPsrJaGN5c7), lote 3, aprovado pelo dono em 20/11 (“pode começar o lote 3”).

## Global Constraints

- Nenhuma regra de negócio muda; a comissão mostrada é a configurada (`COMMISSION_TEACHER_LINK_BPS`, `COMMISSION_MARKETPLACE_BPS`).
- Alvos de toque com 44 px; nada de rolagem lateral a 390 px.
- Nomes dos campos dos formulários continuam os mesmos (o servidor não muda de contrato), salvo o deslocamento, que vira um campo só.

## Review Focus

- **Preço digitado com vírgula ou ponto** (121,00 / 121.00 / 121): “você recebe” mostra os dois valores certos (Task 1).
- **Pausar sem querer:** “Pausar” é secundário e o serviço pausado continua na lista com “Reativar” (Task 1).
- **Séries de uma disciplina:** ligar e desligar a ficha marca a mesma combinação que a tabela marcava; “Todas as séries” liga todas daquela disciplina (Task 2).
- **Menu no celular:** os 7 destinos ficam alcançáveis (4 na barra, 3 no “Mais”), a página atual marcada (Task 3).
- **Primeiro acesso:** sem nome, o professor não passa da tela de boas-vindas; depois, o Início saúda pelo primeiro nome (Task 3).
